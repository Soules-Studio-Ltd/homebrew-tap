# Soules Studio Homebrew tap

The Homebrew tap of Soules Studio LTD.

## MenuBar for HEY

A free, unofficial Mac menu bar app for HEY email. Not affiliated with 37signals.

```sh
brew install --cask soules-studio-ltd/tap/menubar-for-hey
```

The app updates itself, so `brew upgrade` leaves it alone unless you ask with `--greedy`. More at [toolsforhey.com/menubar](https://toolsforhey.com/menubar).
